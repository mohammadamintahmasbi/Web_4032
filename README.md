## About This Project

This project was developed for the **Web and Mobile Programming** course in the Spring of 2025 (1404 AH), during which I served as a Teaching Assistant (TA) for the course, supervised by **[DR.Emadi]**.

The goal of the project was to familiarize students with the concept of **AJAX**. To that end, a simple codebase was provided so that students could send requests to it using AJAX techniques.

The project was hosted on the **Liara** cloud service for a while. It is now remembered simply as a fond memory of that semester :)
